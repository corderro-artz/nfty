# Nfty.Ticket and the `.mnu` Menu format — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract nfty's entire roll into a dependency-free `Nfty.Ticket` assembly, and add a `.mnu`
"Menu" archive that carries a CookBook's weights, rules, colorization and art so an asset can be
rolled and rendered at runtime without the `.cbk`.

**Architecture:** The roll is already image-free; only `Generator.cs` and `GeneratedSet.cs` bind
ImageSharp. The pure files **move** to a new assembly with their namespaces unchanged, so no other
file in the repo changes a `using`. `Generator.RollOne` is then *replaced* by `Ticketer.TryRoll`, so
there is exactly one definition of every decision an asset is made of. A frozen fixture captured
**before** any file moves proves the refactor changed no output.

**Tech Stack:** C# / .NET 10, xunit.v3, `System.Text.Json` (in-box), `System.IO.Compression`.

**Spec:** `docs/superpowers/specs/2026-09-22-nfty-ticket-design.md`
**Overview:** `docs/superpowers/specs/2026-09-22-runtime-and-model-overview.md`

## Global Constraints

- **Zero new NuGet packages.** `Nfty.Ticket` references **no** package at all. `Directory.Packages.props` gains nothing in this plan.
- **Target `net10.0` only.** No `netstandard2.1`, no `#if` in logic anywhere in `Nfty.Ticket`.
- `Directory.Build.props` sets `TreatWarningsAsErrors` and `GenerateDocumentationFile` — **every public member needs an XML `<summary>` or the build fails.** There is no separate lint step.
- Package versions live in `Directory.Packages.props`, never in a csproj.
- Tests are xunit.v3, named `Snake_case_sentences`.
- Tests build fixtures **in memory** from 1×1 or 2×2 solid-fill images; filesystem tests use `Directory.CreateTempSubdirectory()`. No golden-image files.
- **US English** in every identifier, comment, string and doc.
- Every sort that reaches an output file uses `StringComparer.Ordinal`.
- All manifest JSON goes through `Nfty.Core.Formats.Json.Options` (camelCase properties, enums as camelCase strings).
- Every archive is a ZIP with a `manifest.json`; every manifest implements `ISchemaVersioned`.
- **`Schema.Current` is NOT bumped by this plan.** The Menu carries its own separate version line.
- Build: `dotnet build nfty.sln`. Test: `dotnet test nfty.sln`.

```csharp
using System.Globalization;
using System.Security.Cryptography;
using Nfty.Core.Demo;
using Nfty.Core.Formats;
using Nfty.Core.Generation;
using SixLabors.ImageSharp;
using SixLabors.ImageSharp.Formats.Png;

namespace Nfty.Core.Tests;

/// <summary>
/// The roll, recorded before it was extracted into Nfty.Ticket.
///
/// This is the guard that moving the roll out of Generator changed NO OUTPUT THAT HAS EVER BEEN
/// PRODUCED. It only works because it was captured first; a baseline written after a refactor
/// records the refactor's opinion of itself.
///
/// DO NOT REGENERATE THIS FIXTURE TO MAKE A FAILURE GO AWAY. A deliberate change to roll order
/// means a NEW baseline beside this one and a note saying why, exactly as FixtureFreezeTests says
/// about the archives it guards.
/// </summary>
public class TicketFreezeTests
{
    private const string Seed = "nfty-ticket-baseline-0001";
    private const int Count = 200;

    private static string FixturePath() =>
        Path.Combine(AppContext.BaseDirectory, "fixtures", "roll-baseline-chest-demo.txt");

    /// <summary>The demo book's first 200 DNAs plus asset 0001's PNG hash, as one text block.</summary>
    private static string CaptureBaseline()
    {
        string dir = Directory.CreateTempSubdirectory().FullName;
        try
        {
            string cbk = DemoCookBook.WriteTo(dir);   // takes a DIRECTORY, returns the written path
            using var book = CookBookArchive.Read(cbk);
            // GenerateOptions is a POSITIONAL record; Count and Seed have no defaults, so an
            // object initializer does not compile. Use the constructor.
            using var set = Generator.Generate(book, new GenerateOptions(Count: Count, Seed: Seed));

            var sb = new System.Text.StringBuilder();
            foreach (var asset in set.Assets)
                sb.Append(asset.Dna).Append('\n');

            using var ms = new MemoryStream();
            set.Assets[0].Image.Save(ms, new PngEncoder());
            sb.Append("image0001=")
              .Append(Convert.ToHexString(SHA256.HashData(ms.ToArray())).ToLowerInvariant())
              .Append('\n');
            return sb.ToString();
        }
        finally { Directory.Delete(dir, recursive: true); }
    }

    [Fact]
    public void The_demo_book_rolls_exactly_what_it_has_always_rolled()
    {
        string path = FixturePath();
        string actual = CaptureBaseline();

        if (!File.Exists(path))
        {
            // First run only: record the baseline into the SOURCE fixtures folder, not the copy in
            // bin, so it can be committed. Fail loudly so nobody mistakes a capture for a pass.
            string source = Path.Combine(
                AppContext.BaseDirectory, "..", "..", "..", "..", "fixtures",
                "roll-baseline-chest-demo.txt");
            Directory.CreateDirectory(Path.GetDirectoryName(Path.GetFullPath(source))!);
            File.WriteAllText(Path.GetFullPath(source), actual);
            Assert.Fail(
                $"Baseline captured to {Path.GetFullPath(source)}. Commit it, then re-run. "
                + "This failure is expected exactly once.");
        }

        Assert.Equal(File.ReadAllText(path).ReplaceLineEndings("\n"), actual.ReplaceLineEndings("\n"));
    }

    [Fact]
    public void The_baseline_has_the_shape_it_claims()
    {
        // Guards the guard: a truncated or empty fixture would make the test above pass vacuously.
        var lines = File.ReadAllLines(FixturePath());
        Assert.Equal(Count + 1, lines.Length);
        Assert.All(lines.Take(Count), l => Assert.Equal(64, l.Length));
        Assert.StartsWith("image0001=", lines[^1], StringComparison.Ordinal);
    }
}
```

```csharp
using Nfty.Core.Model;

namespace Nfty.Ticket;

/// <summary>Whether a Menu carries its art as one atlas or as a file per variant.</summary>
public enum MenuArtMode
{
    /// <summary>Every variant stitched into one PNG, addressed by the rects in the manifest.</summary>
    Atlas,

    /// <summary>One PNG per variant, under <c>art/</c>.</summary>
    Loose,
}

/// <summary>Where one variant's art sits inside the atlas.</summary>
/// <param name="Key">The cell key, from <see cref="MenuBook.CellKey"/>.</param>
/// <param name="X">Left edge in the atlas, in pixels.</param>
/// <param name="Y">Top edge in the atlas, in pixels.</param>
/// <param name="Width">Cell width.</param>
/// <param name="Height">Cell height.</param>
public record MenuCell(string Key, int X, int Y, int Width, int Height);

/// <summary>How a Menu carries its art.</summary>
/// <param name="Mode">Atlas or loose.</param>
/// <param name="AtlasWidth">The atlas PNG's width; zero in loose mode.</param>
/// <param name="AtlasHeight">The atlas PNG's height; zero in loose mode.</param>
/// <param name="Cells">One entry per distinct image. In loose mode the rects are the whole image,
/// so a reader can treat both modes with one code path.</param>
public record MenuArt(MenuArtMode Mode, int AtlasWidth, int AtlasHeight, IReadOnlyList<MenuCell> Cells);

/// <summary>One layer, as a Menu records it: everything needed to roll and to tint, and no pixels.</summary>
/// <param name="Id">The ingredient id.</param>
/// <param name="Name">The trait_type this layer publishes under.</param>
/// <param name="Kind">Dynamic, Static or Custom.</param>
/// <param name="Colorization">How the layer is colored; null for Custom.</param>
/// <param name="Variants">The weighted variants.</param>
public record MenuLayer(
    string Id, string Name, LayerKind Kind, Colorization? Colorization, IReadOnlyList<Variant> Variants);

/// <summary>One recipe, as a Menu records it.</summary>
/// <param name="Id">The recipe id.</param>
/// <param name="Name">Its display name, published as the <c>Type</c> trait.</param>
/// <param name="Weight">Its weight against the book's other recipes.</param>
/// <param name="LayerOrder">Bottom-to-top paint order — and the order the roll consumes the RNG in,
/// which is why it travels rather than being inferred from <paramref name="Layers"/>.</param>
/// <param name="Layers">Its layers, keyed by the ids in <paramref name="LayerOrder"/>.</param>
/// <param name="Rules">Its incompatibility rules.</param>
/// <param name="AbsentPercent">How often each layer is left out, keyed by ingredient id. A layer
/// absent from this map always appears.</param>
public record MenuRecipe(
    string Id,
    string Name,
    double Weight,
    IReadOnlyList<string> LayerOrder,
    IReadOnlyList<MenuLayer> Layers,
    IReadOnlyList<IncompatibilityRule> Rules,
    IReadOnlyDictionary<string, double> AbsentPercent)
{
    /// <summary>How often <paramref name="ingredientId"/> is left out of this recipe, 0..100.</summary>
    /// <param name="ingredientId">The layer to ask about.</param>
    /// <returns>The recorded percent, or zero when the recipe records none.</returns>
    public double AbsentPercentOf(string ingredientId) =>
        AbsentPercent.TryGetValue(ingredientId, out double p) ? p : 0;
}

/// <summary>
/// A CookBook flattened for runtime: every weight, rule and colorization, plus where the art is,
/// and not one decoded pixel.
/// </summary>
/// <param name="SchemaVersion">The Menu schema this was written against.</param>
/// <param name="SourceCookBookSha256">The hash of the <c>.cbk</c> this came from, or null when it
/// was built from a book that never came from a file. Null means "cannot tell", never "differs".</param>
/// <param name="Canvas">The canvas every variant shares.</param>
/// <param name="CollectionName">What assets are published as — <c>"{name} #{n}"</c>.</param>
/// <param name="CollectionSymbol">The collection's symbol.</param>
/// <param name="Recipes">Its recipes.</param>
/// <param name="Art">Where the art is.</param>
public record MenuBook(
    int SchemaVersion,
    string? SourceCookBookSha256,
    Dimensions Canvas,
    string CollectionName,
    string CollectionSymbol,
    IReadOnlyList<MenuRecipe> Recipes,
    MenuArt Art)
{
    /// <summary>
    /// The key one variant's art is stored under.
    /// </summary>
    /// <param name="recipeId">The recipe the layer belongs to.</param>
    /// <param name="ingredientId">The layer.</param>
    /// <param name="variantId">The variant.</param>
    /// <returns>The cell key.</returns>
    /// <remarks>
    /// <b>Scoped by RECIPE, and that is not redundancy.</b> A <c>.cbk</c> nests a separate
    /// <c>.igt</c> inside each <c>.rcp</c>, so two recipes may each carry an ingredient with the id
    /// <c>bg</c> holding completely different variants. A shallower key collides without a word and
    /// one recipe silently draws another's art.
    /// </remarks>
    public static string CellKey(string recipeId, string ingredientId, string variantId) =>
        $"{recipeId}/{ingredientId}/{variantId}";
}
```

```csharp
using System.Globalization;
using Nfty.Core.Model;

namespace Nfty.Ticket.Tests;

public class AssetTicketWireTests
{
    private static TicketLayer Dynamic(string ing, string v, double h, double s) =>
        new(ing, v, h, s, ColorModel.Hsv, LayerKind.Dynamic, 10, 10);

    private static TicketLayer Custom(string ing, string v) =>
        new(ing, v, null, null, null, LayerKind.Custom, 0, 0);

    private static AssetTicket Make(params TicketLayer[] layers) =>
        new(AssetTicket.ComputeDna("cat", layers), "cat", layers);

    [Fact]
    public void A_ticket_survives_a_wire_round_trip_exactly()
    {
        var original = Make(Dynamic("bg", "a", 137.5, 0.62), Custom("body", "b"));
        var parsed = AssetTicket.Parse(original.ToWire());

        Assert.Equal(original.Dna, parsed.Dna);
        Assert.Equal(original.RecipeId, parsed.RecipeId);
        Assert.Equal(original.Layers, parsed.Layers);
    }

    [Fact]
    public void The_wire_form_is_invariant_across_locales()
    {
        // A comma decimal separator under de-DE would collide with the field separator and produce
        // a ticket that parses to a different colour, or not at all. Every figure that reaches a
        // wire or a file in this product is invariant for this reason.
        var ticket = Make(Dynamic("bg", "a", 137.5, 0.62));
        var previous = Thread.CurrentThread.CurrentCulture;
        try
        {
            Thread.CurrentThread.CurrentCulture = new CultureInfo("de-DE");
            string german = ticket.ToWire();
            Thread.CurrentThread.CurrentCulture = new CultureInfo("en-US");
            Assert.Equal(ticket.ToWire(), german);
            Assert.Equal(ticket.Layers, AssetTicket.Parse(german).Layers);
        }
        finally { Thread.CurrentThread.CurrentCulture = previous; }
    }

    [Fact]
    public void A_tampered_wire_is_refused_rather_than_rendered()
```

```csharp
using System.Globalization;
using Nfty.Core.Generation;
using Nfty.Core.Model;

namespace Nfty.Ticket;

/// <summary>What one layer contributed to a rolled asset.</summary>
/// <param name="IngredientId">The layer.</param>
/// <param name="VariantId">The variant rolled.</param>
/// <param name="Hue">The rolled hue in degrees, or null for a Custom layer.</param>
/// <param name="Sat">The rolled saturation as a 0..1 fraction, or null for a Custom layer.</param>
/// <param name="Model">The color space, or null for a Custom layer.</param>
/// <param name="Kind">Dynamic, Static or Custom.</param>
/// <param name="HueQuantize">The layer's hue bucket width, carried so the DNA can be recomputed
/// from the ticket alone.</param>
/// <param name="SatQuantize">The layer's saturation bucket width, likewise.</param>
public readonly record struct TicketLayer(
    string IngredientId, string VariantId, double? Hue, double? Sat,
    ColorModel? Model, LayerKind Kind, int HueQuantize, int SatQuantize);

/// <summary>
/// One roll, complete, costing no pixels: what a server stores and hands a client.
/// </summary>
/// <param name="Dna">The identity this roll produces.</param>
/// <param name="RecipeId">The recipe rolled.</param>
/// <param name="Layers">The layers that are PRESENT, in <c>layerOrder</c>. An absent layer is
/// omitted entirely.</param>
public sealed record AssetTicket(string Dna, string RecipeId, IReadOnlyList<TicketLayer> Layers)
{
    private const string Version = "v1";

    /// <summary>The DNA a set of layer selections produces.</summary>
    /// <param name="recipeId">The recipe rolled.</param>
    /// <param name="layers">The present layers.</param>
    /// <returns>Lowercase hex SHA-256, identical to what <see cref="Dna.Compute"/> produces for the
    /// same selection — it IS that function; there is no second definition.</returns>
    public static string ComputeDna(string recipeId, IReadOnlyList<TicketLayer> layers) =>
        Dna.Compute(recipeId, layers
            .Select(l => new LayerSelection(
                l.IngredientId, l.VariantId, l.Hue, l.Sat, l.HueQuantize, l.SatQuantize))
            .ToList());

    /// <summary>
    /// The ticket as one line: what goes in a database column or across a network.
    /// </summary>
    /// <returns>
    /// <c>v1|recipe|ing:var[@hue,sat,model,hq,sq]|...|dna</c>. Every figure is INVARIANT — a comma
    /// decimal separator under a European locale would collide with the field separator itself.
    /// </returns>
    public string ToWire()
    {
        var parts = new List<string>(Layers.Count + 3) { Version, RecipeId };
        foreach (var l in Layers)
        {
            string head = $"{l.IngredientId}:{l.VariantId}";
            // ENUMS GO OUT BY NAME, NEVER BY ORDINAL. An (int) cast would pin the DECLARATION
            // ORDER of LayerKind and ColorModel into the wire format, so reordering either enum
            // would silently change what every stored ticket means - a Custom layer reading back as
            // Dynamic, with no error and the wrong pixels. Names are also what Json.Options already
            // does for every enum this product persists (JsonStringEnumConverter).
            parts.Add(l.Hue is double h && l.Sat is double s && l.Model is ColorModel m
                ? string.Create(CultureInfo.InvariantCulture,
                    $"{head}@{h:R},{s:R},{m},{l.HueQuantize},{l.SatQuantize},{l.Kind}")
                : string.Create(CultureInfo.InvariantCulture, $"{head}@,,,,,{l.Kind}"));
        }
        parts.Add(Dna);
        return string.Join("|", parts);
    }

    /// <summary>Reads a ticket back from <see cref="ToWire"/>.</summary>
    /// <param name="wire">The wire form.</param>
    /// <returns>The ticket.</returns>
    /// <exception cref="FormatException">The wire is malformed, is a version this build does not
    /// read, or carries a DNA its own contents do not produce.</exception>
    /// <remarks>
    /// <b>The DNA is recomputed and compared, never trusted.</b> A ticket altered in transit fails
    /// to parse rather than rendering an asset nobody rolled.
    /// </remarks>
    public static AssetTicket Parse(string wire)
    {
        ArgumentNullException.ThrowIfNull(wire);
        var parts = wire.Split('|');
        if (parts.Length < 3) throw new FormatException("A ticket needs a version, a recipe and a DNA.");
        if (parts[0] != Version)
            throw new FormatException($"Ticket version '{parts[0]}' is not one this build reads; expected {Version}.");

        string recipeId = parts[1];
        string dna = parts[^1];
        var layers = new List<TicketLayer>(parts.Length - 3);

        for (int i = 2; i < parts.Length - 1; i++)
        {
            var (head, tail) = Split(parts[i], '@');
            var (ingId, varId) = Split(head, ':');
            var f = tail.Split(',');
            if (f.Length != 6) throw new FormatException($"Layer '{parts[i]}' has {f.Length} fields; expected 6.");

            layers.Add(new TicketLayer(
                ingId, varId,
                f[0].Length == 0 ? null : Num(f[0]),
                f[1].Length == 0 ? null : Num(f[1]),
                f[2].Length == 0 ? null : Enum.Parse<ColorModel>(f[2]),
                Enum.Parse<LayerKind>(f[5]),
                f[3].Length == 0 ? 0 : Int(f[3]),
                f[4].Length == 0 ? 0 : Int(f[4])));
        }

        string recomputed = ComputeDna(recipeId, layers);
        if (!string.Equals(recomputed, dna, StringComparison.Ordinal))
            throw new FormatException(
                "This ticket's DNA is not the DNA its contents produce; it has been altered in transit.");

        return new AssetTicket(dna, recipeId, layers);
    }

    private static (string, string) Split(string s, char at)
    {
        int i = s.IndexOf(at);
        if (i < 0) throw new FormatException($"Expected '{at}' in '{s}'.");
        return (s[..i], s[(i + 1)..]);
    }

    private static double Num(string s) => double.Parse(s, CultureInfo.InvariantCulture);
    private static int Int(string s) => int.Parse(s, CultureInfo.InvariantCulture);
}
```

```csharp
using Nfty.Core.Generation;
using Nfty.Core.Model;

namespace Nfty.Ticket;

/// <summary>
/// A Menu with its draw order and running weight totals already resolved.
/// </summary>
/// <remarks>
/// The same split <see cref="WeightedRoller.Prepare"/> makes, for the same reason: the ordering and
/// the totals are fixed properties of the book, and a server rolling thousands of drops a second
/// must not re-sort and re-sum on every one.
/// </remarks>
public sealed class PreparedMenu
{
    internal PreparedMenu(MenuBook book, WeightedRoller.WeightTable recipes,
                          IReadOnlyDictionary<string, RecipePlan> plans)
    {
        Book = book;
        Recipes = recipes;
        Plans = plans;
    }

    /// <summary>The book this was prepared from.</summary>
    public MenuBook Book { get; }

    internal WeightedRoller.WeightTable Recipes { get; }
    internal IReadOnlyDictionary<string, RecipePlan> Plans { get; }
}

internal sealed record RecipePlan(MenuRecipe Recipe, IReadOnlyList<LayerPlan> Layers);

internal sealed record LayerPlan(
    MenuLayer Layer,
    WeightedRoller.WeightTable Weights,
    double AbsentWeight,
    bool AlwaysAbsent);

/// <summary>
/// The roll: decides a whole asset and touches no pixels.
/// </summary>
/// <remarks>
/// <b>This is the only roll in the product.</b> <c>Generator</c> calls it and keeps only the render,
/// so there is exactly one definition of the order in which layers consume the RNG. Two copies is
/// how "the same seed produces the same collection" stops being true, and the difference would be
/// invisible until a server and a client disagreed about what had been dropped.
/// </remarks>
public static class Ticketer
{
    /// <summary>Resolves a book's draw order and totals, once.</summary>
    /// <param name="book">The Menu to prepare.</param>
    /// <returns>The prepared form, to hand <see cref="TryRoll"/> repeatedly.</returns>
    public static PreparedMenu Prepare(MenuBook book)
    {
        ArgumentNullException.ThrowIfNull(book);

        var recipeWeights = book.Recipes.ToDictionary(r => r.Id, r => r.Weight, StringComparer.Ordinal);
        var plans = new Dictionary<string, RecipePlan>(StringComparer.Ordinal);

        foreach (var recipe in book.Recipes)
        {
            var byId = recipe.Layers.ToDictionary(l => l.Id, StringComparer.Ordinal);
            var layers = new List<LayerPlan>(recipe.LayerOrder.Count);

            foreach (string id in recipe.LayerOrder)
            {
                var layer = byId[id];
                var table = WeightedRoller.Prepare(
                    layer.Variants.ToDictionary(v => v.Id, v => v.Weight, StringComparer.Ordinal));
                double percent = recipe.AbsentPercentOf(id);
                bool never = WeightedRoller.AlwaysAbsent(percent);

                layers.Add(new LayerPlan(layer, table,
                    // Zero for the overwhelmingly common always-present layer, and zero is what makes
                    // the roll below bit-identical to the one that shipped before optional layers.
                    never ? 0 : WeightedRoller.AbsentWeight(percent, layer.Variants.Sum(v => v.Weight)),
                    never));
            }

            plans[recipe.Id] = new RecipePlan(recipe, layers);
        }

        return new PreparedMenu(book, WeightedRoller.Prepare(recipeWeights), plans);
    }

    /// <summary>Rolls one asset.</summary>
    /// <param name="menu">The prepared Menu.</param>
    /// <param name="rng">The run's RNG.</param>
    /// <returns>The ticket, or <see langword="null"/> when the recipe's rules reject the selection —
    /// which is the caller's signal to reroll, exactly as <c>Generator</c>'s loop does.</returns>
    public static AssetTicket? TryRoll(PreparedMenu menu, IRng rng)
    {
        ArgumentNullException.ThrowIfNull(menu);
        ArgumentNullException.ThrowIfNull(rng);

        string recipeId = WeightedRoller.Roll(menu.Recipes, rng);
        var plan = menu.Plans[recipeId];

        var selection = new Dictionary<string, string>(StringComparer.Ordinal);
        var layers = new List<TicketLayer>(plan.Layers.Count);

        foreach (var lp in plan.Layers)
        {
            // A LAYER MAY BE LEFT OUT. It contributes no trait, no pixels and no DNA part — an
            // omission rather than a sentinel, because a PRESENT layer adds a part an absent one does
            // not. Nothing else in this iteration runs, so an absent Dynamic layer rolls no colour,
            // which is what stops two assets that both show nothing from having different DNA.
            string? variantId = lp.AlwaysAbsent
                ? null
                : WeightedRoller.Roll(lp.Weights, lp.AbsentWeight, rng);
            if (variantId is null) continue;

            selection[lp.Layer.Id] = variantId;

            switch (lp.Layer.Kind)
            {
                case LayerKind.Dynamic or LayerKind.Static:
                {
                    var c = lp.Layer.Colorization!;
                    // The ONLY difference between the kinds is where the colour comes from: dynamic
                    // rolls it per asset, static resolves its one fixed colour and consumes NO RNG.
                    var colour = lp.Layer.Kind == LayerKind.Dynamic
                        ? ColorRoller.Roll(c, rng)
                        : ColorRoller.FromFixed(c.Entries[0].Fixed!, c.Model);
                    layers.Add(new TicketLayer(lp.Layer.Id, variantId, colour.H, colour.S,
                        c.Model, lp.Layer.Kind, c.HueQuantize, c.SatQuantize));
                    break;
                }
                default: // Custom — composited as-is, never colorized.
                    layers.Add(new TicketLayer(lp.Layer.Id, variantId, null, null, null,
                        LayerKind.Custom, 0, 0));
                    break;
            }
        }

        if (!RulesEngine.IsLegal(selection, plan.Recipe.Rules)) return null;

        return new AssetTicket(AssetTicket.ComputeDna(recipeId, layers), recipeId, layers);
    }
}
```

```csharp
using Nfty.Ticket;

namespace Nfty.Core.Formats;

/// <summary>
/// Projects a loaded or peeked CookBook into the image-free <see cref="MenuBook"/> the roll works on.
/// </summary>
/// <remarks>
/// Cheap: it copies manifest records that are already in memory and opens no image. That is what lets
/// <c>Generator</c> roll through <c>Ticketer</c> without a second walk of its own.
/// </remarks>
public static class MenuProjection
{
    /// <summary>Projects a decoded book. The book keeps ownership of every image in it.</summary>
    /// <param name="book">The loaded book.</param>
    /// <returns>Its image-free form.</returns>
    public static MenuBook From(LoadedCookBook book)
    {
        ArgumentNullException.ThrowIfNull(book);
        return From(PeekedCookBook.Of(book), book.SourceSha256);
    }

    /// <summary>Projects a manifest-only book.</summary>
    /// <param name="book">The peeked book.</param>
    /// <returns>Its image-free form.</returns>

        {

            var layers = r.Manifest.LayerOrder
                .Select(id => byId[id])
                .Select(i => new MenuLayer(i.Id, i.Name, i.Kind, i.Colorization, i.Variants))
                .ToList();

            return new MenuRecipe(
                r.Manifest.Id,
                r.Manifest.Name,
                book.Manifest.RecipeWeights.GetValueOrDefault(r.Manifest.Id),
                r.Manifest.LayerOrder,
                layers,
                r.Manifest.Rules,
                r.Manifest.AbsentPercent ?? new Dictionary<string, double>(StringComparer.Ordinal));
        }).ToList();

        return new MenuBook(
            MenuSchema.Current, sha, book.Manifest.Canvas,
            book.Manifest.Collection.Name, book.Manifest.Collection.Symbol,
            recipes,
            // Art is filled in by MenuWriter; a projection for rolling alone needs none.
            new MenuArt(MenuArtMode.Loose, 0, 0, []));
    }
}
```

```csharp
using Nfty.Core.Model;

namespace Nfty.Ticket;

/// <summary>One layer to draw.</summary>
/// <param name="ImageKey">What to ask <see cref="MenuArchive.ArtBytes"/> for.</param>
/// <param name="Source">Where this layer's art sits inside those bytes.</param>
/// <param name="Kind">Custom draws as-is; Dynamic and Static are tinted.</param>
/// <param name="Hue">Hue in degrees. Meaningless for Custom.</param>
/// <param name="Sat">Saturation, 0..1. Meaningless for Custom.</param>
/// <param name="Model">The color space. Meaningless for Custom.</param>
public readonly record struct Draw(
    string ImageKey, MenuCell Source, LayerKind Kind, double Hue, double Sat, ColorModel Model);

/// <summary>
/// Turns a ticket into the ordered list of draws that reproduces it.
/// </summary>
/// <remarks>
/// <para><b>Bottom-first, in <c>layerOrder</c></b> — generation's own paint order, which the ticket
/// already carries because <see cref="Ticketer"/> walks the layers in it.</para>
///
/// <para>Nothing here touches a pixel. The colorize rule a renderer must implement is one line:
/// <c>rgb = HsvToRgb(hue, sat, source.R / 255)</c> with the source's alpha carried through
/// untouched — which is exactly what <c>Colorizer.Apply</c> computes, via a 256-entry table it
/// builds because the red channel is the only per-pixel input.</para>
/// </remarks>
public static class Plating
{
    /// <summary>The draws that reproduce a ticket.</summary>
    /// <param name="menu">The Menu the ticket was rolled against.</param>
    /// <param name="ticket">The roll.</param>
    /// <returns>One draw per present layer, bottom-first.</returns>
    /// <exception cref="KeyNotFoundException">The Menu has no art for a layer the ticket names.</exception>
    public static IReadOnlyList<Draw> Plate(MenuArchive menu, AssetTicket ticket)
    {
        ArgumentNullException.ThrowIfNull(menu);
        ArgumentNullException.ThrowIfNull(ticket);

        // KIND AND COLOR MODEL COME FROM THE MENU, NEVER FROM THE TICKET, and that is a
        // correctness rule rather than a tidiness one. Dna.Compute hashes LayerSelection, which
        // carries the variant id and the quantized (H,S) and NOT the kind or the model - so a wire
        // altered in only those two fields recomputes to the same DNA and Parse accepts it. Reading
        // them from the ticket would then let a tampered ticket keep its provable identity while
        // rendering different pixels: flip Custom to Dynamic and the client colorizes art that
        // should composite as-is.
        //
        // The Menu is authoritative and the redundancy is not real: for a given
        // (recipeId, ingredientId) the kind and the color model are fixed BY THE BOOK and cannot
        // legitimately vary per asset. The ticket says what was ROLLED; the Menu says what the layer
        // IS.
        var recipe = menu.Book.Recipes.Single(r => r.Id == ticket.RecipeId);
        var layerById = recipe.Layers.ToDictionary(l => l.Id, StringComparer.Ordinal);

        var draws = new List<Draw>(ticket.Layers.Count);
        foreach (var layer in ticket.Layers)
        {
            string key = MenuBook.CellKey(ticket.RecipeId, layer.IngredientId, layer.VariantId);
            var definition = layerById[layer.IngredientId];
            draws.Add(new Draw(key, menu.Cell(key), definition.Kind,
                layer.Hue ?? 0, layer.Sat ?? 0, definition.Colorization?.Model ?? ColorModel.Hsv));
        }
        return draws;
    }
}
```

- [ ] **Step 2: `BACKLOG.md`** — add an entry with the cost of the deferred TFM

```markdown
## `Nfty.Ticket` does not target `netstandard2.1`

**Status:** deferred deliberately; engine embedding is not a current goal.

`Nfty.Ticket` targets `net10.0` alone. A game engine loading it as a managed plugin would want
`netstandard2.1`, and adding that target later costs: replacing `SHA256.HashData`,
`Convert.ToHexString` and `ArgumentNullException.ThrowIfNull`; an `IsExternalInit` shim for `init`
accessors; and a hand-written reader for the Menu manifest, since `System.Text.Json` is a package
rather than in-box below `net6.0`.

**The rule that keeps it cheap:** `Nfty.Ticket` takes NO package dependency. The only thing a second
target ever has to reconcile is framework API surface.

**And the rule that keeps it correct:** whatever is replaced is replaced UNCONDITIONALLY, not behind
`#if`. A conditional would mean the assembly an engine embeds and the assembly the desktop app loads
run different code to compute a DNA — invisible in review and to any single-target test.
```

Add a **second** entry for the `--voxel` refusal Task 10 ships:

```markdown
## `inspect --voxel` is refused on a `.mnu`

**Status:** deferred on scope, not on principle.

`--voxel` reports which variants carry partial alpha. It is refused on a `.ktn` (which lists paths
without opening them), on a `.tin` (sealed), and on a cooked Set (the output rather than the source
art). **A Menu is the one refused kind where the information genuinely IS present** — it carries
the source variants, uncolorized, which is exactly what the flag scans.

What is missing is the traversal, not the measurement: every `VoxelReport.Scan` overload takes a
`Loaded*` decoded from a `.cbk`, so a Menu needs its atlas decoded and cropped per cell.
`VoxelReport.CountPartial(Image<Rgba32>)` is already public and already does the per-image work.

The refusal message says so in those terms, deliberately — a "cannot" borrowed from one of the other
three arms would be false here, and a wrong reason in an error message is worse than a terse one.
```
