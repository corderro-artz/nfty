# Keyboard shortcuts

Every key and mouse gesture in the app. On a Mac, ++ctrl++ below is ++cmd++, ++alt++ is ++option++,
and the viewer's ++ctrl++-click is a middle-click instead.

The app carries this list too: press ++ctrl+slash++, or click **?** at the right of the status bar, for
the **Quick Reference**. It has four tabs (**Basics**, **Editor**, **Rise & 3D**, **Viewer & runtime**)
and a search box (++slash++ jumps to it; ++enter++ opens the first match; ++esc++ clears it, then
closes the sheet).

!!! note "Letters only work where you are not typing"

    A bare letter is a shortcut only while focus is on the page and not in a text field, so typing a
    name never switches tools.

## Anywhere in the main window

| Keys | Does |
|---|---|
| ++ctrl+slash++ | Open the Quick Reference |
| ++ctrl+w++ | Close the open CookBook or Set |
| ++ctrl+t++ | Switch between light and dark |
| ++ctrl+plus++ / ++ctrl+minus++ | Zoom the whole window in or out |
| ++ctrl+0++ | Window zoom back to 100% |
| ++esc++ | Close the open dialog |

## Opening screen

| Keys | Does |
|---|---|
| ++ctrl+n++ | New CookBook |
| ++ctrl+o++ | Open CookBook |
| ++ctrl+i++ | Import a loose file |

## Explorer

| Keys | Does |
|---|---|
| ++ctrl+k++ | Focus the search box |
| ++alt+up++ / ++alt+down++ | Move the selected layer or Recipe among its siblings (editing unlocked) |
| Drag a tree row | The same move with the mouse |
| ++ctrl++-click or middle-click a row | Open it in the viewer |

## Ingredient Editor

![The Quick Reference, Editor tab: tools, drawing modifiers, marked region, history and canvas view](../images/help-editor-light.png#only-light)

| Keys | Does |
|---|---|
| ++b++ / ++e++ / ++g++ | Brush / eraser / fill |
| ++r++ / ++c++ / ++t++ / ++l++ | Rectangle / circle / triangle / line |
| ++m++ | Select; drag inside the marquee to move |
| ++left-bracket++ / ++right-bracket++ | Shrink / grow the brush |
| ++ctrl+a++ | Mark everything (arms Select) |
| ++delete++ / ++backspace++ | Clear the marked region |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo |
| ++plus++ / ++minus++ / ++0++ | Zoom in / zoom out / fit the canvas |
| Arrow keys | Pan, while zoomed in |
| ++esc++ | Cancel a stroke in progress; otherwise drop the marquee |
| ++shift++ (or ++ctrl++) held while drawing | 45-degree line or stroke; square shape |
| ++alt++ held while drawing a shape | Draw from the center |
| Right mouse button | Erase with the armed tool |
| Wheel / middle-button drag | Zoom about the pointer / pan |
| ++ctrl++-click or middle-click the preview tile | Open it in the viewer |

## Rise page

| Keys | Does |
|---|---|
| ++b++ / ++l++ / ++r++ / ++g++ / ++m++ | Brush / line / rectangle / same-color fill / select |
| ++left-bracket++ / ++right-bracket++ | Shrink / grow the brush |
| ++ctrl+a++ | Mark everything (arms Select) |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo |
| ++plus++ / ++minus++ / ++0++ | Zoom in / zoom out / fit |
| Arrow keys | Pan, while zoomed in |
| Left / right click | Raise the pixel's front / back by one |
| ++shift++ + click | Lower instead of raise |
| ++ctrl++ held while drawing | Constrain: 45-degree line, square rectangle (++shift++ never constrains here) |
| ++alt++ held while drawing a rectangle | Draw from the center |
| ++page-up++ / ++page-down++ | Step the target layer (Recipe roll) |
| ++enter++, or click a rail row | Target that layer (Recipe roll) |
| ++esc++ | Cancel a stroke; else drop the marquee; else drop the target layer. An open dialog takes it first. |
| Wheel / middle-button drag | Zoom about the pointer / pan |
| Middle-click, or ++ctrl++-click without dragging, on the canvas or 3D tile | Open the viewer |

On a Recipe roll, the first click picks the layer that owns the pixel (left: front owner, right: back
owner) and paints nothing.

## 3D view

The Rise page's 3D tile and the viewer's 3D half, while focused.

| Input | Does |
|---|---|
| Left-button drag, or arrow keys | Orbit |
| Right- or middle-button drag | Pan |
| Wheel | Zoom about the pointer |
| ++plus++ / ++minus++ | Zoom |
| ++home++, or double-click | Reset the camera |

## Viewer window

| Input | Does |
|---|---|
| ++1++ / ++2++ / ++3++ | 2D / both / 3D layout |
| ++0++ | Fit the 2D art |
| ++s++ | Next turntable speed |
| ++i++ | Extend the info rail over the window (++esc++ folds it) |
| Wheel over the picture | Zoom about the pointer |
| Left- or middle-button drag | Pan the 2D picture |
| ++ctrl+w++ | Close the viewer window |
| ++esc++ | Close a dialog open in the viewer |

## Set browser and inspector

| Input | Does |
|---|---|
| Click a tile | Open the inspector |
| Right-click a tile | Keep it in the rail without opening |
| ++ctrl++-click or middle-click a tile | Open it in the viewer |
| ++left++ / ++right++ (inspector) | Previous / next asset |
| ++plus++ / ++minus++ / ++0++ (inspector) | Zoom in / zoom out / fit |
| Double-click (inspector) | Toggle 1× and 4× |
| Wheel / drag (inspector) | Zoom / pan |
| ++esc++ (inspector) | Close |

## Dialogs and fields

| Keys | Does |
|---|---|
| ++enter++ | Confirm, in the create and import forms |
| ++esc++ | Cancel or close |
| ++tab++ | Next field; leaving a field commits it |
| Leave a number field empty or unreadable | Its previous value comes back |
