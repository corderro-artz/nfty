# Keyboard shortcuts

The app also carries this list: press ++ctrl+slash++ for the quick-reference sheet.

![The in-app quick reference sheet](../images/help-sheet-light.png#only-light)
![The in-app quick reference sheet](../images/help-sheet-dark.png#only-dark)

## Anywhere in the main window

| Keys | Does |
|---|---|
| ++ctrl+slash++ | Open the quick-reference sheet |
| ++ctrl+w++ | Close the open CookBook or Set |
| ++ctrl+t++ | Switch between light and dark |
| ++ctrl+plus++ / ++ctrl+minus++ | Zoom the whole window in or out |
| ++ctrl+0++ | Reset zoom to 100% |
| ++esc++ | Close the open dialog |

## On the Landing screen

| Keys | Does |
|---|---|
| ++ctrl+n++ | New CookBook |
| ++ctrl+o++ | Open CookBook |
| ++ctrl+i++ | Import a loose file |

## In the Explorer

| Keys | Does |
|---|---|
| ++ctrl+k++ | Focus the search box |
| ++alt+up++ / ++alt+down++ | Move the selected layer, or recipe, up or down among its siblings (editing unlocked) |
| Drag a tree row | The same move with the mouse |

## In the Ingredient Editor

A bare letter is a shortcut only while focus is on the page and not in a text field, so typing a
name into a box never switches tools. On a Mac, ++ctrl++ below is ++cmd++ and ++alt++ is ++option++.

| Keys | Does |
|---|---|
| ++b++ / ++e++ / ++g++ | Brush / eraser / fill |
| ++r++ / ++c++ / ++t++ / ++l++ | Rectangle / circle / triangle / line |
| ++m++ | Select (marquee) |
| ++left-bracket++ / ++right-bracket++ | Shrink or grow the brush |
| ++ctrl+a++ | Select all (also switches to Select) |
| ++delete++ / ++backspace++ | Clear the marked region |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo |
| ++plus++ / ++minus++ / ++0++ | Zoom in, zoom out, fit the canvas |
| Arrow keys | Pan the view, only while zoomed in |
| ++esc++ | Drop the marquee; mid-stroke, cancel the stroke |
| Right mouse button | Erases with whatever tool is armed |
| Wheel / middle-button drag | Zoom about the pointer / pan |
| ++shift++ (or ++ctrl++) held while drawing | 45 degrees for a line, a square box for a shape |
| ++alt++ held while drawing a shape | The press point is the center |
| Ctrl+click or middle-click the corner preview tile | Open it in the viewer (Mac: middle-click only) |

## On the Rise page

The same focus rule applies. The page has five tools, so there is no eraser, circle or triangle key.

| Keys | Does |
|---|---|
| ++b++ / ++l++ / ++r++ / ++g++ / ++m++ | Brush / line / rectangle / same-color fill / select |
| ++left-bracket++ / ++right-bracket++ | Shrink or grow the brush |
| ++ctrl+a++ | Select all (also switches to Select) |
| ++ctrl+z++ | Undo |
| ++ctrl+y++ or ++ctrl+shift+z++ | Redo |
| ++plus++ / ++minus++ / ++0++ | Zoom in, zoom out, fit the canvas |
| Arrow keys | Pan the view, only while zoomed in |
| ++page-up++ / ++page-down++ | Step the target layer (on a recipe roll) |
| ++esc++ | Cancel a stroke in progress; else drop the marquee, then the target layer. An open dialog takes it first. |
| Left click / right click | Raise the pixel's front / back by one |
| ++shift++ + click | Lower instead of raise |
| ++ctrl++ held while drawing | Constrain: 45 degrees for a line, a square for a rectangle (Shift never constrains here) |
| ++alt++ held while drawing a rectangle | The press point is the center |
| Enter, or a click on a rail row | Retarget that layer |
| Wheel / middle-button drag | Zoom about the pointer / pan the canvas |
| Middle-click, or Ctrl+click without dragging, on the canvas; Ctrl+click or middle-click on the 3D tile | Open the viewer (Mac: middle-click only) |

On a recipe roll, the click that picks a pixel's layer paints nothing: the left button picks the
layer that owns the front, the right button the one that owns the back.

## In the 3D view

The 3D tile on the Rise page and the viewer's 3D half share these.
The keys act while the view has focus.

| Input | Does |
|---|---|
| Arrow keys | Orbit the camera one step |
| ++plus++ / ++minus++ | Zoom in or out |
| ++home++ | Reset the camera |
| Left-button drag | Orbit |
| Right- or middle-button drag | Pan |
| Wheel | Zoom about the pointer |
| Double-click | Reset the camera |

## In the viewer window

| Input | Does |
|---|---|
| ++ctrl+w++ | Close the viewer window |
| ++esc++ | Close an open dialog in the viewer (it does not close the window) |
| Wheel over the picture | Zoom about the pointer |
| Left- or middle-button drag | Pan the 2D picture |
| **fit** button (the zoom readout) | Fit |

The 3D half takes the keys and gestures of the 3D view above. The 2D half has no letter or arrow
keys.

## In the Set inspector

| Keys | Does |
|---|---|
| ++left++ / ++right++ | Previous / next asset |
| ++plus++ / ++minus++ / ++0++ | Zoom in, zoom out, fit |
| ++esc++ | Close the inspector |
| Wheel | Zoom about the pointer |
| Drag | Pan |
| Double-click | Toggle between 1x and 4x |

## Anywhere a pop-out button or row appears

| Gesture | Does |
|---|---|
| Ctrl+click or middle-click | Open the asset, tree row or layer row in the viewer (Mac: middle-click only) |

## In any number field

| Keys | Does |
|---|---|
| Leave the field empty or unreadable, then move on | The previous value comes back |

## In any dialog

| Keys | Does |
|---|---|
| ++enter++ | Confirm (in the create dialogs) |
| ++esc++ | Cancel or close |
| ++tab++ | Move between fields |

!!! note "There is no theme button"

    Light and dark are keyboard-only, on ++ctrl+t++. The window chrome carries no theme control by
    design.
