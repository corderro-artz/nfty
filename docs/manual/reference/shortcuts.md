# Keyboard shortcuts

The app also carries this list: press ++ctrl+slash++ for the quick-reference sheet.

![The in-app quick reference sheet](../images/help-sheet-light.png#only-light)
![The in-app quick reference sheet](../images/help-sheet-dark.png#only-dark)

## Anywhere

| Keys | Does |
|---|---|
| ++ctrl+slash++ | Open the quick-reference sheet |
| ++ctrl+n++ | New CookBook |
| ++ctrl+o++ | Open CookBook |
| ++ctrl+i++ | Import a loose file |
| ++ctrl+w++ | Close the open CookBook or Set |
| ++ctrl+t++ | Switch between light and dark |
| ++ctrl+plus++ / ++ctrl+minus++ | Zoom the whole window in or out |
| ++ctrl+0++ | Reset zoom to 100% |

## In the Explorer

| Keys | Does |
|---|---|
| ++ctrl+k++ | Focus the search box |
| ++alt+up++ / ++alt+down++ | Move the selected layer, or recipe, up or down among its siblings (editing unlocked) |
| Drag a tree row | The same move with the mouse |

## On the editor and Rise canvas

A bare letter is a shortcut only while focus is on the page and not in a text field, so typing a
name into a box never switches tools. On a Mac, ++ctrl++ below is ++cmd++ and ++alt++ is ++option++.

| Keys | Does |
|---|---|
| ++b++ | Brush (editor and Rise) |
| ++e++ | Eraser (editor) |
| ++g++ | Fill (editor); same-color fill (Rise) |
| ++r++ | Rectangle |
| ++c++ | Circle (editor) |
| ++t++ | Triangle (editor) |
| ++l++ | Line |
| ++m++ | Select (marquee) |
| ++left-bracket++ / ++right-bracket++ | Shrink or grow the brush |
| ++ctrl+a++ | Select all (also switches to Select) |
| ++delete++ / ++backspace++ | Clear the marked region (editor) |
| ++ctrl+z++ / ++ctrl+y++ | Undo / redo (editor; Rise has its own buttons and one shared history) |
| ++plus++ / ++minus++ / ++0++ | Zoom in, zoom out, fit the canvas |
| Arrow keys | Pan the view, only while zoomed in |
| ++esc++ | Drop the marquee; on Rise, then drop the target layer. An open dialog takes it first. |
| Right mouse button | Erases with whatever tool is armed (editor) |
| ++shift++ (or ++ctrl++) held while drawing | 45 degrees for a line, a square box for a shape |
| ++alt++ held while drawing a shape | The press point is the center |

## On the Rise page

| Keys | Does |
|---|---|
| Left click | Raise the pixel's front by one |
| Right click | Raise the pixel's back by one |
| ++shift++ + click | Lower instead of raise |
| ++page-up++ / ++page-down++ | Step the target layer (on a recipe roll) |
| Enter, or a click on a rail row | Retarget that layer |
| Ctrl+click or middle-click on the 3D tile | Open it in the viewer (Mac: middle-click only) |

On a recipe roll, the click that picks a pixel's layer paints nothing: the left button picks the
layer that owns the front, the right button the one that owns the back.

## Anywhere a pop-out button or row appears

| Gesture | Does |
|---|---|
| Ctrl+click or middle-click | Open the asset, tree row or layer row in the viewer (Mac: middle-click only) |

## In the Ingredient Editor

| Keys | Does |
|---|---|
| ++ctrl+z++ | Undo |
| ++ctrl+y++ | Redo |
| ++esc++ | Drop the current selection marquee |

## In any dialog

| Keys | Does |
|---|---|
| ++enter++ | Confirm (in the create dialogs) |
| ++esc++ | Cancel or close |
| ++tab++ | Move between fields |

!!! note "There is no theme button"

    Light and dark are keyboard-only, on ++ctrl+t++. The window chrome carries no theme control by
    design.
