# Layer order

A Recipe's layers are painted **bottom to top**. Depth 1 paints first and sits furthest back.

You can see the order on the Recipe's detail panel, numbered. To change it: **unlock editing** with
the padlock in the toolbar, then drag a row by its grip — or select a row and press ++alt+up++ /
++alt+down++.

!!! warning "Reordering makes a different collection, not the same one rearranged"

    nfty draws a random number for each layer in order, so moving a layer changes which draw reaches
    it. If you have already cooked a Set from this book, reordering means the next cook produces
    different assets — not the same assets restacked.
