Reused from the app

  • Titlebar, brand mark, breadcrumb, edit-lock chip and status bar are the shell's own.
  • Left rail: the editor's variant cards; the Recipe pane's layer grammar and kind colors; the Set browser's tiles and mono captions.
  • Toolstrip, corner tile with its caption bar, and the grid/step/fit box are the editor's.
  • Rail tabs with count badge, compact steppers, dashed notes, rarity-bar fades for the thickness histogram.
  • Export uses the export dialog's preset cards, radios and accent-barred manifest; Back with unsaved work opens the standard CONFIRM card.

New, built from those parts

  • Depth chip on each source card: front·back, “paper”, or “2D only” in warning ink.
  • Thickness histogram: how many solid pixels stand at each total, so an uneven model is visible before export.
  • Read-only pill over the canvas for recipe and Set sources.
  • Live manifest: file names and an estimated size, updated as format, batch and shape change.
