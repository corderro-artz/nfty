Exploration — colour-mode palette, three treatments

Colour mode makes a Custom layer paintable, and needs somewhere to keep ten ramp slots, the user's saved swatches, the grey to colour mode switch and the opacity lock. The locked mockup set has none of that: today the toolstrip carries one value ramp and one grey swatch. Every treatment below is built from the shipped grammar; the only new hexes are Palette.GrayRamp and Palette.RainbowRamp, which Core computes.

Variant A — palette strip under the toolstrip

recommended

A second 40px row in the canvas pane, directly beneath the tools. Painting state stays with the painting surface, the full pane width is available, and the row is always present — switching mode swaps the ten swatches' fill and nothing moves. The alpha slider's cell is in the layout at all times too: locked, it is dimmed and un-hittable rather than absent.

Variant B — palette section in the colorize rail

alternative

The right rail gains a PALETTE section above the colorize controls. Ten slots in two rows of five inside 300px. Costs the canvas pane nothing — but it puts the colour you are painting with 300px away from the brush, and it competes for the rail's scroll with the reference-layer panel, so at a short window the palette can be scrolled off while you are painting.

Shared — what Save asks when a value-map was painted in colour

all variants

Independent of which variant wins. Colour mode can only ever produce a Custom ingredient, so saving a Dynamic or Static layer that was painted in colour has to say what becomes of the original. The default is non-destructive because a colorization block is not recoverable.

Save as a Custom ingredient?
Colour artwork composites as-is and is never recoloured at generation time, so Ferns will be saved as a new Custom ingredient. The original stays exactly as it is.

Why A

  • Proximity. The colour sits next to the brush that lays it down, not in another pane.
  • Fixed geometry. The strip is one height in both modes and both lock states — the ten slots change fill, and the alpha cell is reserved-but-dimmed rather than appearing. Nothing reflows, which is the house rule the reference panel already follows.
  • It does not compete for scroll. B's palette can leave the viewport while you paint; A's cannot.
  • Cost: 40px of the canvas pane, permanently — including for Dynamic and Static layers, where the strip stays and simply offers the grey ramp. That is the honest trade, and it replaces the toolstrip's single value ramp rather than adding to it.
