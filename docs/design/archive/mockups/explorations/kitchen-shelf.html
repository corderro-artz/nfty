What this pins down for the build:

  • 104px, always. Three states — contents, no Kitchen, empty Kitchen — in one box that never changes size. Opening or closing a workspace reflows nothing.
  • One flat page sequence across kinds. Crossing from the last CookBook page into the first Recipe page is the same gesture as paging within a kind, so there is nothing extra to learn.
  • Page size follows the width. Cards are equal-width and fill the row, so a wider window shows more per page rather than leaving a gap. The last page of a kind keeps its empty slots so the row does not re-space itself mid-sequence.
  • The chevrons never move. At either end they lose ink and hit-testing, not their box — the same rule the editor's alpha control follows.
  • Wheel, chevrons and keyboard all page. A pointer-only control would be the incomplete version of this, the same way pointer-only reorder was.
