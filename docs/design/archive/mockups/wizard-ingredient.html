Colour range ?The band hue and saturation are rolled from. Refine it — and add more weighted ranges — in the editor's Colorize rail.
Hue0° – 360°

Each roll samples this band. Ranges are half-open — the maximum itself is never hit unless both handles meet.
Fixed colour ?Needs an explicit prefix — hex:, rgb:, hsl: or hsv:. A bare value is rejected, never guessed.
hex:d6249f
Only hue and saturation are taken — lightness comes from the grayscale map.
No colorization
Custom layers are composited exactly as painted, so they carry no colour settings at all. Use this for art that must keep its own palette.
